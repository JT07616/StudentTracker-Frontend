# StudentTracker

Klijentski dio aplikacije StudentTracker.

Aplikacija je dostupna na: `https://studenttrackerfipu.netlify.app/login`

## Lokalno pokretanje

Potreban je Node.js i pokrenut poslužiteljski dio na `http://localhost:3000`.

```
npm install
npm run dev
```

Aplikacija se otvara na `http://localhost:5173`.

Adresa poslužitelja čita se iz varijable okoline `VITE_API_URL`; ako nije postavljena, koristi se `http://localhost:3000`.
